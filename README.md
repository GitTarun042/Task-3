# Titanic Exploratory Data Analysis (EDA)

## Objective
Analyze the Titanic dataset to identify factors that influenced passenger survival using data cleaning, feature engineering, and visualization techniques.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Insights
- Most passengers were young adults between ages 20–40.
- Fare showed a positive relationship with survival.
- Passenger class negatively correlated with survival.
- Small-to-medium sized families had higher survival rates.

## Visualizations
- Age Distribution Histogram
- Correlation Heatmap
- Survival Rate by Family Size
